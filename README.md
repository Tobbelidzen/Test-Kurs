# Test-Kurs
Syftet med detta repo är att testa er själva om ni lärt er kursmålen som hör till rymdspelet.

## Kursmål att klara av i repot:
### * Få spelaren att röra på sig i alla 8 led.
### * Gör en instansiering från spelaren.
### * Få spelaren att kollidera med någonting.
### * Förändra en variabel på en annan instans.
